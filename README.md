# SMT Cajuína Puro Sabor - API

Back-end/API do projeto SMT Cajuína Puro Sabor, desenvolvido durante a Sprint 3 do Projeto Integrador.

## Tecnologias

- JavaScript
- Node.js
- Express.js
- PostgreSQL

## Objetivo

Disponibilizar os serviços de back-end necessários para o funcionamento da aplicação, incluindo gerenciamento de usuários, produtos, pedidos e demais funcionalidades previstas no projeto, além da integração com o front-end desenvolvido em React.

## Status

Projeto em desenvolvimento.
